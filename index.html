Como as APIs se comunicam

Uma API é um endereço na internet que devolve dados, quase sempre em JSON. O JSON é a "língua comum": qualquer API fala, e o JavaScript entende. Neste projeto aparecem dois jeitos de combinar APIs:

1. Uma resposta, vários usos (Câmbio)

A AwesomeAPI responde uma vez com todas as cotações. Esse mesmo JSON, guardado na memória, alimenta os cards e o conversor, sem novo pedido. O gráfico usa outro endpoint da mesma API (histórico).

fetch → JSON das cotações → cards
                         → conversor

2. Uma API alimenta a outra (Território)

O ViaCEP devolve o endereço e também o campo ibge, o código oficial da cidade. Esse valor vira a entrada da API do IBGE, que devolve região, estado e microrregião.

CEP → ViaCEP → JSON { ..., "ibge": "2504009" }
       → API do IBGE (usa esse código) → município

Nos bastidores, o arquivo scripts/api.js é a única porta de saída para a internet: faz o fetch, confere erros e converte com .json(). O scripts/app.js só recebe objetos prontos e desenha a tela. Abra os itens "Ver a resposta JSON da API" abaixo para ver o que cada API devolveu de verdade.
