📊 Painel do Brasil & Prática de JSON/APIs

Um projeto desenvolvido para praticar a manipulação de dados em formato JSON, consumo de APIs públicas e estruturação de interfaces modernas utilizando JavaScript ES6+ e Tailwind CSS.

🚀 Tecnologias Utilizadas

HTML5: Estruturação semântica da página.

Tailwind CSS: Estilização moderna e responsiva.

JavaScript (ES6+): Lógica de consumo de dados e manipulação do DOM.

JSON: Armazenamento e estruturação de dados de cotações/moedas locais.


⚙️️ Como Executar o Projeto

Clonar o repositório:

git clone https://github.com/lucaspy2215/Json-Pratica-Api.git


Aceder à pasta do projeto:

cd Json-Pratica-Api


Abrir a aplicação:

Basta abrir o ficheiro index.html em qualquer navegador web, ou utilizar a extensão Live Server no VS.
